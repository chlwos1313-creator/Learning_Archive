# SentiStock (센티스탁)
뉴스 속 숫자를 읽다, 데이터 기반 투자 가이드

## 프로젝트 개요
주식 시장에 쏟아지는 수만 건의 경제 뉴스를 사람이 일일이 읽고 호재/악재를 판단하기는 불가능함.
**SentiStock**은 자연어 처리(NLP) 기술을 활용해 비정형 데이터인 뉴스 텍스트를 -1(부정) ~ 1(긍정) 사이의 정형화된 **감성 점수(Sentiment Score)**로 변환하여 제공하는 서비스임. 
단순한 뉴스 나열을 넘어, 주가 변동 추이와 뉴스 감성 지수를 통합 차트로 제공하여 직관적인 투자 판단을 돕기 위해 기획됨.

## 기술 스택 (Tech Stack)
### Backend
- **Language:** Python 3.10+
- **Framework:** Django (Auth, ORM, Form 적극 활용)
- **Database:** PostgreSQL

### Frontend
- **UI/UX:** HTML5, CSS3, Vanilla JS
- **Visualization:** Chart.js (주가 및 감성 지수 통합 시계열 차트 구현)
- *추후 Vue.js 도입을 통한 SPA(Single Page Application) 고도화 예정*

### Data & AI
- **Data Collection:** 네이버 검색 API (뉴스 텍스트), `FinanceDataReader` (주가 및 KRX 상장 종목 데이터)
- **NLP Model:** Hugging Face `KLUE-RoBERTa` (한국어 금융 도메인 특화 감성 분석 추론)

## 💡 주요 기능 (Key Features)

### 1. 실시간 뉴스 감성 분석 및 지수화
- 특정 종목의 최신 기사를 수집하고 AI 모델을 통해 긍정/부정 수치 도출.
- 감성 지수($S$)와 주가 수익률($R$) 간의 통계적 상관계수($\rho$) 분석 결과를 대시보드에 시각화하여 지표의 신뢰도 확보.

### 2. 주가-감성 통합 차트 (Interactive Chart)
- 캔들 차트(주가)와 라인 차트(감성 지수)를 이중 축으로 결합.
- 뉴스의 긍/부정 반응이 실제 주가 흐름에 미치는 영향을 직관적으로 파악 가능.

### 3. 개인화 맞춤 알림 (Smart Alert)
- 유저별 관심 종목(Watchlist) 등록 및 관리.
- 특정 종목의 감성 점수가 설정한 임계치(예: 긍정 80점 돌파, 부정 40점 미만) 도달 시 즉각적인 대시보드 내 알림 제공.

### 4. 종목별 소통 커뮤니티
- 주주 및 투자자들이 감성 지표를 바탕으로 의견을 나누는 토론 게시판 (게시글, 댓글 CRUD 완비).

## 데이터베이스 모델링 (ERD Core)
- `User`: 커스텀 유저 모델 (회원가입 및 세션 기반 인증)
- `Stock`: KRX 상장 종목 마스터 데이터 (종목코드, 기업명)
- `User_Stock` (M:N): 유저별 찜한 관심 종목 맵핑 테이블
- `News_Sentiment` (1:N): 수집된 뉴스 원문 링크, 발행 일자, 감성 점수, 연관 종목

## 아키텍처 및 파이프라인
1. **수집 (Crawling):** 배치 스크립트로 종목별 최신 뉴스 및 일별 주가 데이터 수집.
2. **전처리 (Pre-processing):** 중복 기사 제거 및 금융 특화 사전 기반 노이즈 필터링.
3. **분석 (Analysis):** KLUE-RoBERTa 모델을 통해 기사 본문 뉘앙스 스코어링.
4. **적재 (Load):** Django ORM을 이용해 PostgreSQL에 날짜 및 종목 기준으로 관계형 데이터 적재.
5. **시각화 (Serve):** 가공된 데이터를 JSON 형태로 넘겨주어 화면에 통합 차트 렌더링.

## 개발 로드맵
- **Phase 1:** 요구사항 분석, ERD 설계 및 Django 프로젝트 초기화
- **Phase 2:** 데이터 수집 파이프라인 구축 및 NLP 감성 모델 테스트 적용
- **Phase 3:** 백엔드 핵심 비즈니스 로직(관심 종목, 게시판, 점수 산출 API) 개발
- **Phase 4:** 프론트엔드 대시보드 UI 구현 및 시각화(Chart) 연동
- **Phase 5 (Next Step):** DRF(Django REST Framework) 도입을 통한 API 서버로의 전환 및 Vue.js 프론트엔드 완전 분리
