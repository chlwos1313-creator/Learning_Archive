# SSAFY 15기 관통 프로젝트

# 금융 자산 커뮤니티 웹 애플리케이션

## 1. 프로젝트 소개
본 프로젝트는 주식, 코인 등 금융 자산에 대해 자유롭게 토론하고 정보를 공유할 수 있는 커뮤니티 게시판입니다. 
가입한 사용자들은 각 자산별 게시판에서 글을 작성/수정/삭제할 수 있으며, LLM(대규모 언어 모델)을 접목하여 부적절한 게시글 작성을 사전에 차단하고 사용자의 투자 성향을 분석해주는 심화 기능을 제공합니다.

## 2. 설치 및 실행 방법

### 요구 사항
- Python 3.11 이상
- Django 5.x
- 기타 패키지: `requirements.txt` 참고

### 설치 절차
1. 저장소 클론 및 가상환경 설정
```bash
git clone <repository_url>
cd <repository_folder>
python -m venv venv
```

2. 가상환경 활성화 (Windows 기준)
```bash
venv\Scripts\activate
```

3. 패키지 설치
```bash
pip install -r requirements.txt
```

4. LLM API 설정
현재 코드는 `community/llm.py` 내부에 Upstage API Key가 적용되어 바로 작동합니다.
(필요 시 해당 파일의 `_build_llm_client` 함수에서 키를 변경할 수 있습니다.)

5. 데이터베이스 마이그레이션 및 서버 실행
```bash
python manage.py makemigrations
python manage.py migrate
python manage.py runserver
```

## 3. 주요 기능 설명

- **회원 관리 (`accounts` 앱)**: 
  - 커스텀 유저 모델(`CustomUser`)을 활용한 닉네임, 프로필 이미지, 다중 관심종목 저장 기능.
  - 회원가입 후 자동 로그인 처리 및 비밀번호 변경 기능.
  - 사용자 프로필 페이지에서 가입 정보 및 작성한 게시글 모아보기 지원.
  
- **커뮤니티 게시판 (`community` 앱)**:
  - 금융 자산별(삼성전자, 비트코인 등) 독립적인 토론 게시판 지원.
  - 작성자 본인만 수정 및 삭제가 가능하도록 권한 방어 로직 적용.
  - 각 게시글 목록에서 작성자의 상태(내 글, 탈퇴자 여부 등) 시각적 피드백 제공.

## 4. 분석 흐름 (LLM)
본 프로젝트는 OpenAI (또는 Upstage)의 LLM API를 활용해 다음과 같은 지능형 분석을 수행합니다.

1. **사전 필터링 로직**: 
   - 사용자가 새로운 게시글을 작성하거나 수정하여 저장 버튼을 누를 때 폼 유효성 검사 단계에서 제목과 내용을 취합하여 LLM API에 전달.
   - 사전에 설정된 시스템 프롬프트(우회 욕설 판독 등)를 기반으로 부적절성 여부 판단 후 `YES` 또는 `NO` 텍스트 반환.
   - `YES`가 반환되면 저장을 막고 경고 메시지(`messages.error`)를 반환합니다.

2. **투자 성향 분석**: 
   - 사용자가 프로필 페이지에서 "투자 성향 분석 (AI)" 버튼을 클릭하면 AJAX 요청이 발생.
   - 서버에서 해당 사용자가 최근에 작성한 게시글 최대 10개를 텍스트로 병합하여 LLM에 분석 요청.
   - LLM이 컨텍스트(글의 내용과 분위기)를 파악해 "가치투자자", "단기트레이더" 등의 성향 분석 텍스트를 응답하면, 화면을 새로고침하지 않고 즉시 사용자에게 보여줍니다.
