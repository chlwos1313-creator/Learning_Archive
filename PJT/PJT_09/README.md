## 2. ✨ 구현 기능 설명 (요구사항 매칭)

* **[F101] Proxy 서버 설계**
* 클라이언트가 외부 모델 서빙 API에 직접 접근하지 않고 고유 Proxy 엔드포인트(`/api/v1/chat`)로만 소통하도록 단일 창구를 개설하여 보안성과 제어력을 확보했습니다.



* **[F102] Guardrail API 구현**
* 사용자의 입력문 내 유해 키워드(마약, 범죄, 불법 등)를 실시간 검증하여 정형화된 Bool 스키마(result, reason)로 안전성을 선제 판단하는 보안 필터를 구현했습니다.



* **[F103] 텍스트 요청/응답 처리**
* 가드레일을 통과한 안전한 질의에 한하여 경량 LLM 컴포넌트의 자연스러운 텍스트 응답 콘텐트를 사용자 화면으로 중계합니다.



* **[F104] 상태 중심 챗봇 UI 구성**
* 비동기 데이터 통신(Fetch API)의 지연 시간 동안 유저에게 최적의 UX를 제공하기 위해, "가드레일 판단중" ➡️ "답변 생성중"으로 이어지는 단계별 로딩 스피너 및 진행 상태 출력을 완성했습니다.



* **[F105] 멀티모달 이미지 생성 엔드포인트**
* 유저의 드로잉 텍스트 명령어(예: "~ 그려줘")의 맥락을 분석하여 동적으로 이미지 에셋 URL을 매칭하고, 프론트엔드 화면상에 HTML `<img>` 태그로 렌더링 배치했습니다.



* **[F106] LLM 답변 적합도 스코어링**
* 생성된 텍셋 및 이미지 결과물이 사용자의 초기 질문 의도에 얼마나 부합하는지 100점 만점 기준으로 평가 점수 및 정성적 사유(Reason)를 함께 도출하여 시각화했습니다.



* **[F110] 심화: TTS(Text-to-Speech) 오디오 인터페이스**
* 생성된 대화형 텍스트 결과물을 음성 신호로 변환하여, 사용자가 웹 화면 내 `[🔊 음성 듣기]` 버튼을 누르면 실시간 스트리밍 음성이 출력되도록 멀티모달 오디오 구동 엔진을 연동했습니다.

## 3. 🧠 학습 내용 및 기술적 요약

* **FastAPI 라우팅 및 Pydantic 유효성 검증**
* HTTP 통신 시 주고받는 데이터 바디 스키마를 Pydantic `BaseModel`로 엄격히 제한함으로써, 명세서 규격에 맞지 않는 예외적 호출을 엔드포인트 초입 단계에서 완벽히 방어할 수 있었습니다.



* **Proxy 패턴과 가드레일 아키텍처**
* 백엔드 내부에서 특정 보안 검사(Guardrail) 로직을 먼저 거친 후 최종 타깃 비즈니스 로직으로 전개하는 프록시 아키텍처의 흐름을 이해하고 실제 코드로 유기적인 함수 체이닝을 구현했습니다.



* **비동기 흐름 제어와 동적 UI 렌더링**
* 자바스크립트의 `async/await` 구문을 통해 백엔드 처리 상태 변화에 맞춰 로딩 문구를 가변적으로 업데이트하고, DOM 조작을 통해 텍스트, 이미지, 버튼 등 멀티모달 레이아웃을 유연하게 결합하는 웹 프론트엔드 메커니즘을 학습했습니다.
