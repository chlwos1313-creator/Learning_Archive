# 5과목: 정보시스템 구축 관리 핵심 요약

---

## 1. 소프트웨어 개발 보안 구축
### 보안의 3요소
* **기밀성(Confidentiality):** 인가된 사용자만 접근 가능.
* **무결성(Integrity):** 인가된 사용자만 수정 가능, 정보의 정확성 유지.
* **가용성(Availability):** 필요할 때 언제든 사용 가능.

### Secure SDLC (보안 개발 생명주기)
* **Seven Touchpoints:** 실무적으로 검증된 개발 보안 방법론.
* **CLASP:** 초기 단계 보안 강화를 목적으로 함.
* **CWE:** 소프트웨어 보안 취약점을 표준화한 목록.

## 2. 암호화 및 인증
### 암호화 알고리즘
* **대칭키 (개인키):** 암호화/복호화 키가 동일. (속도 빠름, 키 관리 어려움)
    * 종류: DES, AES, SEED, ARIA.
* **비대칭키 (공개키):** 암호화키(공개)와 복호화키(비밀)가 다름. (키 관리 쉬움, 속도 느림)
    * 종류: RSA, Diffie-Hellman, ECC.
* **해시(Hash):** 단방향 암호화, 무결성 검증에 사용. (SHA-256, HAS-160 등).

### 접근 제어 (Access Control)
* **DAC (임의적 접근 제어):** 데이터 소유자가 사용자 신분에 따라 권한 부여.
* **MAC (강제적 접근 제어):** 시스템이 보안 등급(허가 권한)에 따라 권한 부여.
* **RBAC (역할 기반 접근 제어):** 사용자의 역할(직무)에 따라 권한 부여.

## 3. 네트워크 및 시스템 보안 공격
### 서비스 거부 공격 (DoS / DDoS)
* **SYN Flooding:** TCP의 3-Way Handshake 취약점 이용, 접속 자원 고갈.
* **Smurfing:** ICMP Echo 패킷을 직접/브로드캐스트로 보내 응답 폭주 유도.
* **Ping of Death:** 거대 패킷을 조각내어 전송, 재조합 과정에서 시스템 부하.

### 기타 주요 공격 기법
* **SQL Injection:** 웹 폼에 SQL 구문을 삽입해 DB 정보를 탈취하거나 조작.
* **XSS (크로스 사이트 스크립팅):** 악성 스크립트를 삽입해 사용자 정보를 탈취.
* **Sniffing:** 네트워크상의 데이터를 몰래 가로채는 행위.
* **Spoofing:** 승인받은 사용자인 것처럼 속이는 행위 (IP, ARP 등).

## 4. 프로젝트 관리 (비용 및 일정)
### 비용 산정 모델
* **LOC (Line of Code):** 원시 코드 라인 수를 기준으로 산정.
* **COCOMO:** 보헴(Boehm) 제안, 규모에 따라 Organic, Semi-Detached, Embedded로 구분.
* **Putnam:** Rayleigh-Norden 곡선을 기초로 함, SLIM 도구 활용.
* **기능 점수 (FP):** 소프트웨어의 기능을 정량화하여 산정.

### 일정 관리 도구
* **PERT:** 비관치, 기대치, 낙관치를 사용하여 일정을 계산.
* **CPM (임계 경로법):** 프로젝트를 완성하기 위한 가장 긴 경로를 찾아 일정 관리.
* **간트 차트 (Gantt Chart):** 막대 그래프 형태의 공정표.

---

## 5. 신기술 및 인프라 (IT Trend)
* **클라우드 컴퓨팅:** IaaS(인프라), PaaS(플랫폼), SaaS(소프트웨어).
* **Docker:** 컨테이너 기반 가상화 오픈소스 프로젝트.
* **디지털 트윈:** 현실 세계 사물을 가상 공간에 구현해 시뮬레이션.
* **Mesh Network:** 무선 랜 구성 요소들이 그물망처럼 연결된 형태.
* **MQTT:** IoT 환경에서 경량 메시지를 전송하는 프로토콜.
* **RAID:** 여러 개의 하드디스크를 하나로 묶어 성능과 안정성 향상.
