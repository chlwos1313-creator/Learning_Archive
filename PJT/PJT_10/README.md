# 은행 찾기 서비스

Kakao Map API 기반 은행 위치 검색 및 자동차 길찾기 서비스

---

## 프로젝트 개요

지역(광역시/도, 시/군/구)과 은행명을 선택하면 해당 지역의 은행 지점을 지도에 표시하고, 멀티캠퍼스 강남에서 선택한 은행까지의 자동차 경로 및 예상 시간과 요금을 안내하는 웹 서비스입니다.

---

## 주요 기능

| 기능 | 설명 |
| :--- | :--- |
| 지역 선택 | 광역시/도 선택 시 시/군/구가 연동되는 드롭다운 메뉴 기능 |
| 은행 선택 | 국내 주요 은행 목록 제공 및 선택 기능 |
| 마커 표시 | 검색 결과를 지도에 번호 순서대로 마커 표시 |
| 인포윈도우 | 마커 또는 목록 클릭 시 상세 정보를 보여주는 팝업 창 기능 |
| 자동차 길찾기 | 멀티캠퍼스 강남에서 선택한 은행까지의 실시간 자동차 경로 안내 |
| 경로 정보 제공 | 주행 예상 시간, 거리, 택시 요금, 통행료 정보 표시 |

---

## 기술 스택

프론트엔드: HTML5, CSS3, Vanilla JavaScript

라이브러리 및 API: Kakao Map JavaScript SDK, Kakao Mobility REST API

백엔드 (개발용 프록시): Python 3 (내장 모듈: http.server, urllib)

## 프로젝트 후기 및 느낀 점

이번 프로젝트를 진행하면서 가장 크게 배운 점은 웹 보안 정책인 CORS에 대한 이해입니다. 외부 API인 Kakao Mobility API를 브라우저에서 직접 호출했을 때 발생하는 차단 문제를 해결하는 과정에서, 클라이언트와 API 서버 사이에서 중개자 역할을 하는 '프록시 서버'의 필요성 깨달았습니다.

웹 애플리케이션을 개발할 때 무조건 프론트엔드에서 데이터를 다 가져올 수 없으며, 보안과 정책에 따라 백엔드 아키텍처가 왜 필요한지 그 흐름을 깊이해하는 좋은 계기가 되었습니다.
