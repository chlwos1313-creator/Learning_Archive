# 2과목: 소프트웨어 개발 핵심 요약

---

## 1. 자료구조 (Data Structure)
### 선형 구조 (Linear Structure)
* **배열 (Array):** 정적 구조, 동일 이름 변수 사용, 첨자 사용.
* **스택 (Stack):** 후입선출 (**LIFO**), 자료의 삽입/삭제가 한쪽 끝에서만 발생. (인터럽트 처리, 수식 계산)
* **큐 (Queue):** 선입선출 (**FIFO**), 한쪽은 삽입(Rear), 다른 한쪽은 삭제(Front).
* **데크 (Deque):** 리스트 양쪽 끝에서 삽입/삭제 가능.
* **선형 리스트:** 연속 리스트(배열 이용)와 연결 리스트(포인터 이용)로 구분.

### 비선형 구조 (Non-Linear Structure)
* **트리 (Tree):** 노드와 가지로 구성된 사이클 없는 그래프.
    * **트리 순회:** 전위(Root-L-R), 중위(L-Root-R), 후위(L-R-Root).
* **그래프 (Graph):** 정점(Vertex)과 간선(Edge)의 집합. 방향/무방향 그래프.

## 2. 정렬 및 알고리즘
### 주요 정렬 알고리즘
* **선택 정렬 (Selection):** 최소값을 찾아 맨 앞과 교체.
* **삽입 정렬 (Insertion):** 데이터를 적절한 위치에 삽입하며 정렬.
* **버블 정렬 (Bubble):** 인접한 두 데이터를 비교하여 위치 교환.
* **퀵 정렬 (Quick):** 피벗을 기준으로 분할 정렬 (평균 $O(n \log n)$).
* **힙 정렬 (Heap):** 완전 이진 트리를 이용한 정렬.

### 알고리즘 시간 복잡도 (Big-O)
* $O(1)$ < $O(\log n)$ < $O(n)$ < $O(n \log n)$ < $O(n^2)$ < $O(2^n)$
* **해싱 함수:** 중첩법, 제산법, 기수변환법, 숫자분석법 등.

### 알고리즘 설계 기법
* **Divide and Conquer:** 분할 정복.
* **Dynamic Programming:** 동적 계획법 (작은 문제의 연장선).
* **Greedy:** 탐욕법 (현 시점 최적의 해 선택).
* **Backtracking:** 해를 찾다 막히면 부모 노드로 되돌아감.

## 3. 애플리케이션 테스트
### 테스트 원리
* **결함 집중 (파레토 법칙):** 20%의 모듈에서 80%의 결함 발생.
* **살충제 패러독스:** 동일한 테스트 케이스 반복 시 더 이상 결함 발견 불가.
* **오류-부재의 궤변:** 요구사항을 만족하지 못하면 결함이 없어도 품질이 낮음.

### 테스트 분류
* **화이트박스 테스트:** 모듈 내부 소스 코드 논리 경로 테스트 (조건 검사, 루프 검사 등).
* **블랙박스 테스트:** 요구사항 명세 기반 기능 테스트 (동치 분할, 경계값 분석 등).
* **검증 (Verification):** 개발자 시각, 생산 과정 테스트.
* **확인 (Validation):** 사용자 시각, 결과물 테스트.

### 개발 단계에 따른 테스트 (V-모델)
1. **단위 테스트:** 모듈/컴포넌트 중심.
2. **통합 테스트:** 모듈 결합 과정 테스트 (**하향식: 스텁(Stub)** 필요, **상향식: 드라이버(Driver)** 필요).
3. **시스템 테스트:** 전체 시스템 작동 확인.
4. **인수 테스트:** 사용자 요구사항 충족 확인 (알파, 베타 테스트).

## 4. 소프트웨어 통합 및 형상 관리
### 빌드 자동화 도구
* **Ant:** 자바 프로젝트 공식 빌드 도구 (XML 기반).
* **Maven:** 의존성 설정 및 라이브러리 관리.
* **Gradle:** Groovy 기반, 안드로이드 공식 빌드 도구.
* **Jenkins:** 지속적 통합(CI) 도구.

### 소프트웨어 형상 관리 (SCM)
* 소프트웨어 변경 사항을 체계적으로 관리 (식별 → 통제 → 감사 → 기록).
* **버전 관리 도구:** 공유 폴더, 클라이언트/서버(CVS, SVN), 분산 저장소(Git, Bitkeeper).

### EAI (Enterprise Application Integration)
* 기업 내 각종 앱 간의 상호 연동 방식.
* **Point-to-Point, Hub & Spoke, Message Bus, Hybrid.**

## 5. 인터페이스 및 품질 분석
* **데이터 형식:** JSON (속성-값 쌍), XML (태그 기반 확장 가능 언어).
* **인터페이스 검증 도구:** xUnit, STAF, Selenium 등.
* **코드 품질 분석:**
    * **정적 분석:** 실행 없이 코드 결함 확인 (pmd, checkstyle 등).
    * **동적 분석:** 실행 중 결함 확인 (Valgrind, Avalanche 등).
