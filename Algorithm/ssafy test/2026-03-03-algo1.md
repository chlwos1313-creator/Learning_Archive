# 문제1 : 단어만들기(배점: 40점)
import 사용금지
N×N 격자에는 다음과 같은 칸이 존재한다.
- 0 : 통로
- 1 : 벽
- 2 : 술래
격자에는 술래가 1명 또는 2명 존재한다.
각 술래는 자신의 위치에서
상, 하, 좌, 우 네 방향으로 직선상의 칸을 감시할 수 있다.
감시는 한 칸씩 진행하며 벽을 만나면 즉시 중단된다.
격자에 대한 정보가 주어질 때 감시를 피할 수 있는 통로 칸의 수를 출력하라.
다음은 두 번째 테스트케이스로 감시를 피할 수 있는 10개의 칸이 존재한다.
술래가 두 명인 경우 감시 영역은 교차할 수 있다.


**[입력]**
첫 번째 줄에 테스트케이스의 개수 T가 주어진다.
다음 줄부터 각 테스트케이스 별로 첫 번째 줄에 격자의 크기 N, 다음 N 줄에
걸쳐 빈 칸으로 구분된 격자의 정보가 주어진다. (3 ≤ N ≤ 10)

**[출력]**
각 테스트케이스마다 ‘#tc’(tc는 테스트케이스 번호), 빈 칸에 이어 답을
출력한다.

**[답안]**
```python
import sys; sys.stdin = open('algo1_sample_in.txt')
T = int(input())
dr = [1, 0, -1, 0]
dc = [0, -1, 0, 1]
for tc in range(1, 1+T):
    N = int(input())
    grid = [list(map(int, input().split())) for _ in range(N)]
    sule = []
    ans = 0
    for i in range(N):
        for j in range(N):
            if grid[i][j] == 2:
                sule.append((i, j))  # 술래가 있는 좌표들을 모두 찾아 리스트에 저장

    for r, c in sule:  # 술래리스트에서 한 명씩 가져옴
        for k in range(4):
            nr = r + dr[k]
            nc = c + dc[k]
            while 0 <= nr < N and 0 <= nc < N and grid[nr][nc] != 1:  # 상하좌우 방향으로 감시되는 구역 찾기
                grid[nr][nc] = 3
                nr += dr[k]
                nc += dc[k]

    for i in range(N):
        for j in range(N):
            if grid[i][j] == 0:
                ans += 1
    # 감시구역이 아닌 구역 확인
    print(f'#{tc} {ans}')
```
