# 머신러닝 기초: 회귀에서 신경망까지

## - 1. 선형 회귀 (Linear Regression)

선형 회귀는 독립 변수 $X$와 종속 변수 $y$ 사이의 선형 상관관계를 모델링하여 미래의 값을 예측하는 가장 대표적인 통계적 기법임.

기본 개념: 데이터를 가장 잘 표현하는 단 하나의 '직선'을 찾는 과정임.오차 최소화: 이 직선은 데이터 포인트들과의 거리 차이(오차)의 합이 최소가 되는 지점을 지남.

수식: $y = wx + b$$w$ (Weight): 가중치 혹은 기울기. 입력 데이터가 결과에 주는 영향력을 의미함.
$b$ (Bias): 편향 혹은 절편. 입력값과 상관없이 기본적으로 더해지는 값임.

학습 목적: 실제 정답($y$)과 모델의 예측값($\hat{y}$) 사이의 차이인 오차를 줄이기 위해 최적의 $w$와 $b$를 결정함.

평가 방법: 주로 MSE(Mean Squared Error)를 손실 함수로 사용하여 값이 0에 가까워지도록 최적화함.

## - 2. 다중 선형 회귀 (Multiple Linear Regression)

현실의 복잡한 문제는 하나의 변수만으로 설명되지 않음. 다중 선형 회귀는 여러 개의 독립 변수를 사용하여 결과를 예측함.

수식: $y = w_1x_1 + w_2x_2 + \dots + w_nx_n + b$

특징: 여러 개의 입력 특성(Features)이 각각의 가중치를 가지고 결과값에 기여함.

차원 확장: 변수가 1개일 때는 '선'이었지만, 변수가 2개면 '평면', 3개 이상이면 '초평면(Hyperplane)'의 형태로 데이터를 설명함.

행렬 연산: 계산의 편의를 위해 가중치 벡터 $W$와 입력 데이터 벡터 $X$의 내적으로 계산하며, $y = XW + b$로 간결하게 표현함.

## - 3. 오즈 (Odds)와 선형식분류 

문제를 풀기 위한 로지스틱 회귀의 핵심 개념으로, 확률을 선형 회귀식으로 연결하기 위한 다리 역할을 함.오즈(Odds): 사건이 발생할 확률($p$)을 발생하지 않을 확률($1-p$)로 나눈 값임.
$Odds = \frac{p}{1-p}$

로짓(Logit) 변환: 오즈에 자연로그를 취한 것임. 이를 통해 확률값(0~1)을 전 범위($-\infty$ ~ $+\infty$)의 실수로 변환하여 선형 회귀식과 등호를 성립시킴.

$\ln\left(\frac{p}{1-p}\right) = wx + b$

시그모이드(Sigmoid) 함수: 로짓 식을 다시 $p$에 대해 정리한 결과임. 어떤 선형식의 결과값도 0과 1 사이의 확률값으로 변환해 줌.

$p = \sigma(z) = \frac{1}{1 + e^{-z}}$ (여기서 $z = wx + b$)

Getty Images의미: 이를 통해 "이 데이터가 클래스 A일 확률은 80%임"과 같은 이진 분류 판단이 가능해짐.

## - 4. Shallow 네트워크 (얕은 신경망)

입력층, 단일 은닉층, 출력층으로 구성된 가장 기본적인 인공신경망 구조임.네트워크 도식화구조: 데이터가 들어오는 입력층(Input), 데이터의 비선형 특징을 추출하는 은닉층(Hidden), 최종 결과를 내는 출력층(Output)으로 구성됨.

특징: 단순 선형 회귀로는 해결할 수 없는 복잡한 패턴을 '비선형 활성화 함수'를 통해 학습할 수 있음.각 단계별 상세 계산 과정입력 데이터 $X$, 1층 가중치 $W^{(1)}$, 2층 가중치 $W^{(2)}$라고 할 때의 흐름임.

Step 1: 은닉층 선형 결합 (Z1 계산)입력값에 가중치를 곱하고 편향을 더해 선형 합을 구함.$z^{(1)} = W^{(1)}X + b^{(1)}$

Step 2: 은닉층 활성화 (A1 계산)$z^{(1)}$에 비선형 활성화 함수(ReLU, Sigmoid 등)를 씌워 신경망에 유연함을 부여함.$a^{(1)} = \sigma(z^{(1)})$

Step 3: 출력층 선형 결합 (Z2 계산)은닉층의 결과값 $a^{(1)}$을 다시 입력으로 받아 다음 가중치를 곱함.$z^{(2)} = W^{(2)}a^{(1)} + b^{(2)}$

Step 4: 최종 출력 (Y_hat 계산)마지막 활성화 함수를 통과시켜 최종 예측값을 산출함.$\hat{y} = \sigma(z^{(2)})$
