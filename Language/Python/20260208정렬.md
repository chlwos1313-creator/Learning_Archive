# 정렬

## 버블정렬
- 개념: 인접한 두 원소를 비교하여, 앞의 원소가 뒤의 원소보다 크면 서로 자리를 바꾸는 스왑 방식. 이 과정을 바복하면 가장 큰 원소가 리스트의 맨끝으로 이동하게 됨.

- 동작과정:
 1. 첫 번째 원소와 두 번쨰 원소 비교 -> 교환 여부 결정.
 2. 두 번쨰와 세 번쨰 비교..(반복)
 3. 1회전이 끝나면 맨 뒤에 확정된 원소를 제외하고 반복

- 예제코드
```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n - 1, 0, -1): # 뒤에서부터 정렬 범위를 줄여나감
        for j in range(i):
            if arr[j] > arr[j+1]: # 앞의 수가 더 크면
                arr[j], arr[j+1] = arr[j+1], arr[j] # 교환(Swap)
    return arr
```

## 선택 정렬

- 개념: 정렬되지 않은 전체 구간에서 최소값 또는 최대값을 찾아 가장 앞쪽의 원소와 자리를 바꾸는 방식.

- 동작과정
 1. 주어진 리스트 전체를 훑어서 최소값을 찾음
 2. 그 최소값을 리스트의 맨 앞에 있는 값과 교환

 3. 맨 앞의 값을 제외하고 나머지 구간에서 다시 최소값을 찾아 반복

- 예제코드
```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        min_idx = i # 일단 i번째가 제일 작다고 가정
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]: # 더 작은 값을 발견하면
                min_idx = j # 인덱스 갱신
        arr[i], arr[min_idx] = arr[min_idx], arr[i] # 최소값과 현재 위치 교환
    return arr
```

## 카운팅 정렬

- 개념: 항목들의 순서를 결정하기 위해 집합에 각 항목이 몇 개 등장하는지 세어 그 정보를 바탕으로 정렬하는 알고리즘.

- 제약조건:
 1. 데이터가 정수여아함.
 2. 데이터의 범위가 메모리에 담을 수 있을 만큼 작아야함.(수 억 단위로 가면 부적합)

- 동작 과정:
 1. 입력 배열을 훑으며 각 숫자가 몇 번 나왔는지 count배열에 기록
 2. count 배열을 누적 합으로 갱신.
 3. 입력 배열을 뒤에서부터 순호하며, 해당 숫자를 결과 배열의 알맞은 위치에 배치하고 counts를 하나 줄임.

- 예제코드
```python
def counting_sort(arr):
    if not arr: return []

    max_val = max(arr)
    counts = [0] * (max_val + 1) # 인덱스 0부터 max_val까지 생성

    # 1. 각 숫자 개수 세기
    for num in arr:
        counts[num] += 1

    # 2. 누적 합 계산 (위치 결정을 위해)
    for i in range(1, len(counts)):
        counts[i] += counts[i-1]

    result = [0] * len(arr)

    # 3. 뒤에서부터 순회하며 배치 (안정성 보장을 위해 뒤에서부터)
    for num in reversed(arr):
        idx = counts[num] - 1
        result[idx] = num
        counts[num] -= 1

    return result
```
