# 문제1 : 단어만들기(배점: 40점)
import 사용금지
최근 금값이 급등하자 스타티는 금을 찾아 광산을 개발하려고 한다. 스타티는
금 광산 채굴권을 낙찰 받았지만, 계약 조건에 따라 지도에 표시된 여러 광산
후보지 중 단 하나의 지역만 선택하여 개발할 수 있다.
주어진 N X N 크기의 지도에서 스타티가 채굴 할 수 있는 최대 금 채굴량과
해당 지역 크기를 출력하는 프로그램을 작성하시오.


**[입력]**
첫번째줄에테스트케이스의개수T가주어진다.
각테스트케이스의첫번째줄에지도의크기N 이주어지며, 다음N줄에걸쳐서N X N 크기의광산지도가주어진다. 단, 금맥이없는경우는입력으로주어지지않는다.
(5 ≤ N ≤ 10 )

**[출력]**
각테스트케이스마다#tc (tc는1부터시작하는번호)를출력한뒤, 한칸띄고금의최대채굴량과해당광산의크기를공백으로구분하여출력한다.만약금의최대채굴량이동일한광산이여러개존재한다면, 광산의크기(연결된칸의수)가더작은것을출력한다.

**[답안]**
```python
T = int(input())
dr = [1, 0, -1, 0]
dc = [0, -1, 0, 1]

for tc in range(1, 1+T):

    def func(r, c):  # 금괴 총합 구하는 함수 정의
        global gold
        global cnt
        max_gold = -999999999999
        for k in range(4):
            nr = r + dr[k]
            nc = c + dc[k]
            if 0 <= nr < N and 0 <= nc < N and not v[nr][nc] and grid[nr][nc] != 0:
                v[nr][nc] = 1
                gold += grid[nr][nc]
                cnt += 1
                func(nr, nc)  # 인접한곳에 금괴가 있다면 재귀
        if max_gold < gold:
            max_gold = gold
        return max_gold, cnt

    N = int(input())
    grid = [list(map(int, input().split())) for _ in range(N)]
    v = [[0] * N for _ in range(N)]
    rst = []
    for i in range(N):
        for j in range(N):
            if grid[i][j] != 0 and not v[i][j]:
                v[i][j] = 1
                gold = grid[i][j]
                cnt = 1
                rst.append(func(i, j))

    rst_max = 0
    rst_min = -999999999
    for maxi, mini in rst:
        if maxi > rst_max:
            rst_max = maxi
            rst_min = mini
        elif maxi == rst_max:
            rst_min = min(mini, rst_min)  # 나온 값들 중 금괴가 최대인 경우와 그 중 가장 작은 광산의 크기일때를 구함
    print(f'#{tc} {rst_max} {rst_min}')
```
