# 프로젝트 구현 회고 (README)

## 1. 단계별 구현 과정 중 학습한 내용

- **HTML 구조화**: `index.html`과 `portfolio.html`을 생성하며 웹 페이지의 전체적인 뼈대를 잡는 방법을 복습했습니다. 목적에 맞는 태그(`form`, `input`, `textarea`, `nav`)를 적절히 배치하는 것을 연습했습니다.
- **CSS 스타일링 및 반응형 웹**: Bootstrap의 Grid 시스템(`.row`, `.col-md-*`, `.col-*` 등)과 유틸리티 클래스를 활용하여 빠르고 일관된 디자인을 적용하는 방법을 학습했습니다. 또한, 미디어 쿼리(`@media`)와 Bootstrap의 반응형 클래스를 사용하여 768px 미만의 모바일 환경에서 레이아웃이 1열 구조로 자연스럽게 변경되도록 처리했습니다.
- **폼(Form) 요소 설계**: 회원 정보 및 투자 성향을 입력받기 위해 `type="email"`, `type="number"`, `radio`, `checkbox` 등 다양한 input 타입을 활용하고 데이터 변형을 막기 위한 `readonly`, `disabled` 속성의 차이를 이해하고 적용했습니다.

## 2. 어려웠던 부분

- **프리미엄 UI (Glassmorphism) 세부 조정**: 배경색이 투과되면서도 텍스트 가독성을 해치지 않게 하는 반투명 효과를 구현할 때, `backdrop-filter: blur()`와 배경색의 `rgba` 투명도 값을 적절히 조합하여 세련된 유리 질감을 표현하는 값비율을 찾는 것이 다소 까다로웠습니다.
- **상세 레이아웃 조정**: 요구사항에 맞춰 좌우 패널의 균형을 맞추고, 각 입력 요소 간의 여백(Margin, Padding)을 시각적으로 불편함 없이 일관성 있게 구성하는 데 시행착오가 있었습니다.

## 3. 새로 배운 것들

- **CSS 트랜지션 및 시각 효과**: 단순한 배치를 넘어 `box-shadow`와 `transition` 속성을 활용해 프로필 이미지나 버튼에 마우스를 올렸을 때(hover) 입체감이 생기고 부드럽게 반응하는 마이크로 인터랙션을 새롭게 적용해 보았습니다.
- **그라디언트 활용**: 밋밋한 단색 배경 대신 `linear-gradient`를 사용하여 트렌디한 웹 애플리케이션의 느낌을 연출하는 방법을 익혔습니다.

## 4. 느낀 점

명세서의 요구사항(F301~F305)을 차근차근 따라가며 기본 기능을 구현한 뒤, 반응형과 심미적인 요소(F310)를 추가로 얹어보는 과정이 매우 흥미로웠습니다. 코드를 작성할 때 사용자가 실제로 각 폼을 입력하고 페이지를 탐색하는 경험(UX)을 고려하여 너비나 배열을 결정해야함을 느꼈습니다. 이번에 만든 정적인 화면을 바탕으로 향후 JavaScript를 연동해 동적으로 데이터를 검증하고 저장하는 기능도 구현해보고 싶습니다.
