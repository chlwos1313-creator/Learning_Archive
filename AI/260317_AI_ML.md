# 3-3 Learning 이란

- 주어진 데이터에서 정답을 가장 잘 맞출 수 있도록 모델의 규칙을 조금씩 조정해가는 과정
- 데이터 > 가설공간 > 선택된 모델 f

학습에 필요한 3가지 : Data, Hypothesis Space, 선택기준

학습과정
1. 가성공간에서 하나의 함수를 선택
2. 그 함수로 데이터의 모든 예시를 예측
3. 손실함수로 틀린 정도 계산
4. 더 적게 틀리도록 함수의 파라미터 조정
5. 반복하여 최적의 모델 완성

## 왜 f(x)를 학습하는가?

예측
잘 학습된 f가 있다면, 새로운 입력 X = x 에서 **반응/목표** Y를 예측할 수 있음

중요 특성 파악
- 피쳐들 x중 어떤 **특성**이 y를 설명하는데 중요하고, 어떤 것은 덜 중요한지 알 수 이씅ㅁ

해석 가능성
- f의 복잡도에 따라 각 구성요소 Xi가 Y에 **어떻게 영향을 미치는지 이해**할 수 있음

# 학습 시작

- 지도학습 : 입력 + 정답을 가지고 예측 규칙을 배우는 방법
- 목표 : 훈련 데이터 뿐만 아니라 처음 보는 데이터에서도 예측 성능 향상

## 1-1 지도학습이란?

- 정답 라벨이 있는 훈련 데이터를 사용해 예측 모델을 학습하는 방법
- 목표: 훈련 데이터로 학습한 모델이 새로운 데이터에서도 정확한 예측을 수행

훈련데이터 -> 레이블링 -> 학습 -> 모델 생성 및 적용 -> 결과 확인

## 1-2 지도학습의 종류 (회귀 VS 분류)

### 회귀(Regression)
- 예측하고 싶은 결과값이 **숫자**일 때 사용
- 특징: 라벨 및 예측 모델의 출력은 연속적인 수치

평균 제곱 오차(MSE)
- y 값과 y hat의 평균 제곱 차이값
- 틀린 정도를 제곱하여 더 큰 오류에 페널티 부여
  - 전체 평균 오류 수준을 한 눈에 볼 수 있음
  (RMSE 루트제곱근도 사용)


결정계수(R-squared)

- y의 분산 중에서 x로 설명되는 비율
$$R^2 = 1 - \frac{\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{n}(y_i - \bar{y})^2}$$

- 1에 가까울수록 설명력이 높고 값이 낮을 가까울 수록 설명력이 낮음(매우 나쁜 경우 음수도 가능은 함)

| 구분 | MSE (Mean Squared Error) | R-squared ($R^2$, 결정계수) |
| :--- | :--- | :--- |
| **의미** | 예측값과 실제값 차이(오차)의 제곱 평균 | 모델이 데이터를 얼마나 잘 설명하는지의 비율 |
| **공식** | $$MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$|$$R^2 = 1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2}$$ |
| **판단 기준** | **0에 가까울수록** 우수 | **1에 가까울수록** 우수 |
| **데이터 스케일** | 단위에 영향을 받음 (절대적 수치) | 단위에 영향을 받지 않음 (상대적 수치) |
| **특징** | 오차가 커질수록 값이 급격히 증가 (Penalty) | 모델의 성능을 0~1(또는 그 이하) 사이로 직관적 표현 |

### 분류(Classfication)

- 예측하고 싶은 결과값이 **범주**일 때 사용
- 특징: 범주 라벨(이진/다중)

분류 모델은 label이 범주로 되어 있기 때문에 mse나 r-squ 사용하기 어려움

분류 정확도(Accuracy)
- 전체 예측 중에서 올바르게 맞춘 예측의 비율
- **불균형 데이터에서는 정확도가 높더래도 좋은 모델이 아닐 수 있음**
  -> 정확도는 단순히 "전체 중 맞춘 비율" 만 계산함
  -> 정확도만 보지 말고 다른 지표(예:혼동행렬)도 함께 봐야 안전

혼동 행렬(Confusion Matrix) 

- TP (True Positive): 양성을 양성으로 잘 맞춤 (정답)

- TN (True Negative): 음성을 음성으로 잘 맞춤 (정답)

- FP (False Positive): 음성인데 양성으로 잘못 예측 (오탐 - Type I Error)

- FN (False Negative): 양성인데 음성으로 잘못 예측 (미탐 - Type II Error)

| | 실제 Positive (1) | 실제 Negative (0) |
| :--- | :---: | :---: |
| **예측 Positive (1)** | **TP** (정답) | **FP** (오탐) |
| **예측 Negative (0)** | **FN** (미탐) | **TN** (정답) |

Overfittin 과적합

- 훈련 데이터의 우연한 패턴이나 잡음까지 외워버려서 훈련에서는 잘 맞지만 테스트에서 성능이 나빠지는 현상
- 훈련오류 급격히 낮음, 테스트 오류 높음
