# 🎱 [TIL] 일타싸피(SSAFYcial Hit) 알고리즘 정리

SSAFY의 꽃, **일타싸피** 프로젝트를 진행하며 학습한 물리 법칙 기반의 당구 봇 알고리즘을 정리합니다.

---

## 1. 개요
소켓 통신으로 전달받은 각 공의 좌표 정보를 바탕으로, 내 공(White Ball)이 목적구(Target Ball)를 타격하여 홀(Pocket)에 넣기 위한 **최적의 각도와 힘**을 계산합니다.

## 2. 핵심 물리 원리 및 기하학

### 🎯 충돌 지점(Target Point) 계산
단순히 목적구를 향해 쏘는 것이 아니라, 목적구가 홀로 들어갈 수 있는 **연장선상의 접점**을 찾아야 합니다.
* **충돌 지점:** 목적구 중심에서 홀의 반대 방향으로 공의 지름($2r$)만큼 떨어진 지점입니다.



### 📐 삼각함수를 이용한 각도 산출
* **`math.atan2(dy, dx)`**: 두 점 사이의 상대적인 각도를 라디안 값으로 반환합니다.
* **각도 보정**: 일반적인 수학적 좌표계(x축 기준 0도)와 일타싸피의 좌표계(12시 방향 기준 0도, 시계방향 증가)를 일치시켜야 합니다.
  * $degree = (90 - \theta) \pmod{360}$

## 3. 알고리즘 구현 프로세스
1. **데이터 수신**: 현재 공들의 위치와 내 공의 좌표를 수신합니다.
2. **목적구 및 홀 선정**: 가장 넣기 쉬운 위치의 목적구와 타겟 홀을 매칭합니다.
3. **Target Point 산출**: 목적구와 홀의 직선 경로를 기반으로 내 공이 부딪혀야 할 좌표를 구합니다.
4. **샷 실행**: 계산된 각도와 거리에 따른 힘(Power)을 소켓으로 전송합니다.

---

## 4. 핵심 코드 (Python)

```python
import math

def get_shot_control(white_x, white_y, target_x, target_y, hole_x, hole_y):
    # 공의 반지름 (규격에 맞춰 수정 필요)
    r = 5.73 / 2 

    # 1. 목적구에서 홀까지의 각도 구하기
    dx_target_hole = hole_x - target_x
    dy_target_hole = hole_y - target_y
    angle_to_hole = math.atan2(dy_target_hole, dx_target_hole)

    # 2. 내 공이 닿아야 하는 실제 목표 지점(Target Point) 계산
    # 목적구 중심으로부터 홀 반대 방향으로 2r만큼 떨어진 지점
    target_point_x = target_x - (math.cos(angle_to_hole) * r * 2)
    target_point_y = target_y - (math.sin(angle_to_hole) * r * 2)

    # 3. 내 공에서 Target Point까지의 거리와 각도 계산
    dx = target_point_x - white_x
    dy = target_point_y - white_y
    
    # 수학적 각도를 도 단위로 변환
    angle_rad = math.atan2(dy, dx)
    angle_deg = math.degrees(angle_rad)
    
    # 일타싸피 좌표계(12시 방향 0도, 시계방향 증가)로 보정
    final_angle = (90 - angle_deg) % 360
    
    # 4. 거리 기반 힘(Power) 조절
    distance = math.sqrt(dx**2 + dy**2)
    final_power = distance * 0.7 # 계수는 실험을 통해 조정
    
    return final_angle, final_power
