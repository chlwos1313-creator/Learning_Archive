# 알고리즘
문제를 해결하기 위한 **절차나 방법**.

**알고리즘의 시간 복잡도**: 알고리즘의 작업량을 표현할 때 시간 복잡도로 표현

- 실제 걸리는 시간을 측정
- 실행되는 명령문의 개수를 계산

시간 복잡도 표시
- 빅 오 표기법을 언급한느 경우가 많음
- 시간 복잡도 함수중에서 가장 큰 영향력을 주는 n에 대한 항만을 표시
- 계수는 생략하여 표시
**ex.** O(3n + 2) = O(3n) = O(n)

## 배열

1. 입력 받은 정수를 1차원 배열에 저장하는 방법

```python
N = int(input())
arr = list(map(int, input().split())) 
```

2. 배열 원소의 합 s 계산하기

```python
s = 0
for i in range(N):
  s += arr[i]
```

배열 원소 중 최댓값 찾기

```python
max_val = arr[0]
for i in range(1, N):
  if max_val < arr[i]:
    max_val = arr[i]
```

배열 원소 중 최댓값의 인덱스 max 찾기
**최댓값이 여러개인 경우 <=**

```python
max_idx = 0
for i in range(1, N):
  if arr[max_idx] < arr[i]:
    max_idx = i
```
