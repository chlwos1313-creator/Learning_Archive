# **[D4] 햄버거 다이어트**

## **1. 문제 개요**
- **문제:** 정해진 **제한 칼로리(L)**를 넘지 않으면서, 재료 조합의 **맛 점수 합**을 최대화하기.
- **입력:** 재료 수 N, 제한 칼로리 L, 각 재료의 맛 점수 T와 칼로리 K.
- **유형:** **자료구조 & 알고리즘 (DP, 0/1 Knapsack)**

---

## **2. 접근 방법 (Why DP?)**
- **문제점:** 모든 재료의 조합을 확인하면 2^N의 시간이 걸림. N=20이면 약 100만 번이라 괜찮을 수 있지만, N이 커지면 바로 터짐.
- **해결책:** **이전의 계산 결과를 저장(Memoization)**하여 중복 계산을 막는 DP 사용.
    1. **`dp` 배열의 의미:** `dp[c]`는 칼로리 `c`를 썼을 때 얻을 수 있는 **최대 맛 점수**.
    2. **역순 업데이트의 이유:** 앞에서부터 채우면 "방금 추가한 재료"를 같은 물건 취급해서 또 더해버리는 오류(중복 선택)가 발생함.



---

## **3. 핵심 문법 정리**

### **① DP 테이블 정의**
- **`dp = [0] * (L + 1)`**: 인덱스 자체가 '현재까지 소모한 칼로리'를 의미함. 처음엔 아무것도 안 먹었으니 0으로 초기화.

### **② 점화식 (핵심 로직)**
- **`dp[c] = max(dp[c], dp[c - calorie] + score)`**
    - `dp[c]`: 이 재료를 **안 넣었을 때**의 최적값.
    - `dp[c - calorie] + score`: 이 재료를 **넣기 위해** 자리를 비우고 현재 점수를 더한 값.

### **③ 파이썬 `range` 활용**
- **`range(L, calorie - 1, -1)`**: `L`부터 시작해서 `calorie`까지 1씩 줄어들며 반복. (역순 탐색)

---

## **4. 최종 코드 (Python)**

```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    
    for t in range(1, T + 1):
        N, L = map(int, input().split())
        
        dp = [0] * (L + 1)
        
        for _ in range(N):
            score, calorie = map(int, input().split())
            
            for c in range(L, calorie - 1, -1):
                if dp[c - calorie] + score > dp[c]:
                    dp[c] = dp[c - calorie] + score
        
        print(f"#{t} {dp[L]}")

solve()
